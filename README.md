# Parking-management-using-stack

About the Project
This project is a simple Parking Garage Simulator developed using HTML, CSS, and JavaScript. It demonstrates the **Stack data structure** by simulating how cars enter and leave a narrow parking garage.

Cars can leave only in the reverse order in which they entered, following the **LIFO (Last In, First Out)** principle.

Features
- Park a car by entering its name.
- Remove the most recently parked car.
- Display all parked cars.
- Show an alert when the parking garage is empty.
- Simple and user-friendly interface.

 Technologies Used
- HTML
- CSS
- JavaScript

 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in any web browser.
3. Enter a car name and click **Park Car**.
4. Click **Remove Car** to remove the last parked car.

 Data Structure Used
**Stack (LIFO — Last In, First Out)**

The `push()` operation adds a car to the stack, while the `pop()` operation removes the most recently added car.

 Example
If cars enter in this order:

- Car A
- Car B
- Car C

They leave in this order:

- Car C
- Car B
- Car A

 Learning Outcomes
- Understanding the Stack data structure.
- Learning the LIFO principle.
- Using JavaScript arrays and their `push()` and `pop()` methods.
- Practicing HTML, CSS, and JavaScript.

Project Type
Data Structures Case Study / Beginner Web Development Project.
